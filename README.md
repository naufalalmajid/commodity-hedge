# commodity-hedge

trying to learn about hedge inventory on commodity this is a simple repo for learning hedging concepts in a small company


### direct hedge (single commodity)
ex: cotton

really useful when you have a lot of stock inventory, cost is fixed, current margin is good, but production is limited

### spread hedge (multi commodity)
ex: corn and ethanol

really useful when processing raw material into finished product — protecting the margin between input and output price from moving against each other
